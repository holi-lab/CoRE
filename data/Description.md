CoRE ships the Contextual Hop Editing Dataset (CHED) for measuring how robust a knowledge edit remains under diverse contextual cues. After cloning the repository, unzip `CHED.zip` in this folder to access `CHED.json`, a list of dictionaries describing each editing case (prompts, edited knowledge, locality checks, hop words, and supporting sentences). The corpus contains 21,782 fact triplets and more than 640k contextual sentences spanning subject/object hops and locality variants. Use these files as the data source when running the editing pipelines in `CoRE/edit_eval`, and keep the structure unchanged to stay compatible with the provided scripts.
